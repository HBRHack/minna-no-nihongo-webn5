# Minna no Nihongo II — JLPT N4 (Bab 26 – 50)

Folder ini disiapkan untuk **Seri 2**: lanjutan resmi dari [`01-minna-no-nihongo-n5/`](../01-minna-no-nihongo-n5/README.md) yang mencakup **Bab 26 – 50** buku *Minna no Nihongo Shokyuu II* (みんなの日本語 初級 II) untuk tingkat **JLPT N4**.

## Struktur Folder

- [`bahan-sumber/`](./bahan-sumber/) — Tempat menaruh PDF, catatan, atau daftar kosakata sumber Bab 26–50 sebelum diekstrak.
- [`catatan-materi/`](./catatan-materi/) — Tempat menyimpan draf markdown Bab 26–30, 31–35, 36–40, 41–45, dan 46–50 (mengikuti format N5: Kotoba + Bunpou + Kaiwa + Latihan menyatu per bab).

---

## Peta Silabus Minna no Nihongo II (Bab 26 – 50)

| Kelompok Bab | Fokus Tata Bahasa (Bunpou) Inti |
| :--- | :--- |
| **Bab 26 – 30** | Penjelasan & alasan (`んです`), **Bentuk Potensial / Bisa** (`可能形`), `ながら`, `し` (penambahan alasan), `～てあります` & `～ておきます` (persiapan). |
| **Bab 31 – 35** | **Bentuk Maksud / Ajakan Kasual** (`意向形` + `と思っています`), `つもりです`, `ほうがいいです`, **Bentuk Perintah & Larangan** (`命令形・禁止形`), **Bentuk Bersyarat `～ば` & `～なら`**. |
| **Bab 36 – 40** | `ようにします・ようになります`, membungkus klausa dengan `の` (`のは・のが・のを`), dugaan `でしょう・かもしれません`, pertanyaan sisipan (`～かどうか` / kata tanya + `か`), `てみます`. |
| **Bab 41 – 45** | Memberi/menerima sopan (`いただきます・くださいます・やります`), tujuan (`ために・のに`), dugaan visual (`そうです`), `すぎます`, `やすい・にくい`, `ばあいは`, `のに` (padahal). |
| **Bab 46 – 50** | `ところ` (tepat akan/sedang/baru saja), `はず` (seharusnya), kabar angin (`そうです` / `ようです`), **Bentuk Pasif (`受身`)**, **Bentuk Kausatif (`使役`)**, & **Keigo (`尊敬語` / `謙譲語`)**. |
